## Overview
This repository contains three standalone client-side JavaScript exercises demonstrating DOM manipulation, event handling with `addEventListener()`, input validation, and dynamic element generation.

## How to Run
1. Clone or download this repository.
2. Open any folder (`Q1/`, `Q2/`, or `Q3/`) and launch `index.html` in a modern desktop browser (or via VS Code Live Server).
